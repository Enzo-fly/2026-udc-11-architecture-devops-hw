# UDC Workshop 11 — Архітектура та DevOps з AI

- **Слайди:** <https://koldovsky.github.io/2026-udc-11-architecture-devops-slidev/>
- **Повні інструкції:** [`docs/walkthrough.md`](docs/walkthrough.md)

Домашнє завдання на **одній невеликій системі** — «Поштомат громади»: архітектурне
рішення (ADR), діаграма як код, розбір інциденту з RCA і post-mortem, деплой і CI за
детермінованими перевірками. Головне питання воркшопу — **чого AI не знав про вашу
систему?** Тому кожну задачу ви проганяєте з AI щонайменше двічі, з різним контекстом,
і чесно порівнюєте.

## Що потрібно

- Node 22+ (`npm install` не потрібен — у репо немає жодної npm-залежності)
- Git Bash (на Windows), GitHub account, Agentic IDE в агентному режимі (Claude Code;
  Cursor — Agent; Copilot — Agent mode): AI має сам читати файли й запускати команди
- **Жодних API-ключів, хмарних акаунтів і Docker.** Docker знадобиться лише для одного
  з бонусних шляхів.

## Швидкий старт

```bash
gh repo fork koldovsky/2026-udc-11-architecture-devops-hw --clone
cd 2026-udc-11-architecture-devops-hw
git checkout -b ws11/<github-username>

cd app && npm test && cd ..   # 15 зелених тестів
npm run check:deploy          # PASS 0  FAIL 9  SKIP 4 — так і має бути
```

`npm run check:deploy` на засіяній конфігурації деплою **падає — це очікувано**:
виправити її — частина Task D. Перший запуск один раз завантажує `yaml@2.8.1` через
`npx` (потрібна мережа), далі перевірка працює офлайн з npm-кешу.

## Що вже є

| Шлях | Що це |
|---|---|
| `app/` | Сервіс «Поштомат громади»: API, worker для SMS, нічна задача, тести |
| `materials/` | Бриф нової функції і документи команди |
| `docs/ops/` | Операційні runbook-и |
| `incident/` | Дані інциденту 2026-10-14: алерти, логи, метрики, історія деплоїв |
| `deploy/` | Поточні `Dockerfile` і `compose.yaml` |
| `pipeline/` | Сюди — ваш `deploy.yml` |
| `tools/` | `check-deploy.mjs` — детермінований перевіряльник деплою і його тести |
| `ai-runs/` | Сюди — перші відповіді AI, дослівно |
| `docs/templates/` | Шаблони для всіх документів домашки |

## Що робите ви

| Задача | Що | Час |
|---|---|---|
| **Task A** | ADR з AI: той самий запит без матеріалів і з ними | ~45 хв |
| **Task B** | Діаграма як код: C4 у Mermaid, кожна стрілка — з доказом у коді | ~30 хв |
| **Task C** | Інцидент і RCA з AI, post-mortem, runbook | ~60 хв |
| **Task D** | Деплой і CI з AI + власне детерміноване правило перевірки | ~45 хв |
| **Task E** (бонус) | Один шлях: стек у Docker / STRIDE / оцінка вартості | ~30 хв |

Разом ~3 години без бонусу. Помітну частину цього часу агент працює сам: прогін над
даними інциденту — це кілька хвилин його роботи.
