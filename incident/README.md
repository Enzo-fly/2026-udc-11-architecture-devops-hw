## Формат

- Увесь час — Europe/Kyiv, ISO 8601 зі зміщенням `+03:00`.
- Логи — JSON lines, по одному об'єкту в рядку: `ts`, `level`, `msg` і поля події.
- **API пише в лог кожну відповідь 5xx, а з решти запитів — кожен сотий**
  (`ACCESS_LOG_EVERY` у `app/src/server.js`). Тож кількість рядків `"msg":"request"`
  — це приблизно 1 % трафіку; частку помилок рахуйте з метрик або з `rps`.
- Worker пише кожну відправлену пачку SMS і кожну відповідь 429 від провайдера.
- `/health` у лог не потрапляє.

## Метрики

Один рядок — одна хвилина, `ts` — її початок.

| Колонка | Що це |
|---|---|
| `rps` | запитів до API за секунду, середнє за хвилину |
| `p95_ms` | 95-й перцентиль часу відповіді API, мс |
| `error_rate` | частка відповідей 5xx (0.01 = 1 %) |
| `db_pool_in_use` | зайняті з'єднання пулу БД у процесі API, максимум за хвилину |
| `db_pool_waiting` | запити API, що чекали на з'єднання з пулу, максимум за хвилину |
| `heap_used_pct` | heapUsed / heapTotal процесу API, % |
| `sms_429_per_min` | відповіді 429 від SMS-провайдера за хвилину (worker) |
