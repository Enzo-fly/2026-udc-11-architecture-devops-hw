# Архітектура «Поштомата громади»

_Оновлено: червень 2026 (v1.5)._

## Схема

```text
 мешканець ──► екран поштомата ──► API ──► PostgreSQL ◄── worker ──► SMS-провайдер
                                    ▲                       │
 служба доставки (сканер) ──────────┘                       └── SMS з кодом мешканцю
```

## Компоненти

- **API** (`src/server.js`) — Node.js, HTTP. Сканер служби доставки реєструє посилку
  (`POST /parcels`), екран поштомата надсилає код (`POST /pickup`), персонал дивиться
  список (`GET /admin/parcels`), моніторинг опитує `GET /health`.
- **Worker** (`src/worker.js`) — кожні 30 секунд бере посилки без сповіщення і шле SMS з
  4-значним кодом отримання через HTTP API SMS-провайдера.
- **PostgreSQL** — на тій самій VM, поза контейнерами. Таблиці: посилки, події, сесії
  персоналу.
- **Нічна задача** (`bin/expire-parcels.js`) — позначає посилки, що пролежали понад
  72 години, як повернені.

## Розгортання

Одна VM, `docker compose` з двома сервісами (`api`, `worker`) з одного образу —
див. `deploy/` у корені репозиторію. Налаштування — змінні оточення, список — у
`src/config.js`.
